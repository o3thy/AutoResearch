## Third stage: Zotero Analytical Workflow Skills

The `obsidian/` module integrates the source, seven agent Skills, templates and
tools from [Zotero-Analytical-Workflow-Skills](https://github.com/cheneternity/Zotero-Analytical-Workflow-Skills),
commit `6b3202cfb74b9221c3b8048b1dab99e0a294a496`, with the two locally tested
SQLite compatibility fixes preserved. The source snapshot and hashes are
recorded in `obsidian/UPSTREAM.json`; the original README and installation guide
are retained in that module. Project-specific handoff and CLI files are new.

## ResearchRabbit: ResearchPilot-Skills

The ResearchRabbit skill workflow, quality checks, and shared paper fields in this
project are adapted from [ResearchPilot-Skills](https://github.com/JosephElvisMaman1/ResearchPilot-Skills),
local source commit `ee9262a2b66b39ba6fda8c06b5310661935935f9`.

Source paths: `skills/thesis-researchrabbit-expand/SKILL.md`,
`skills/thesis-researchrabbit-expand/references/quality-check.md`, and
`schemas/paper.schema.json`. Browser adapter, HTML parser, CLI, and capture tests
are new implementation for AutoResearch. Upstream had skill instructions,
not a standalone ResearchRabbit browser execution script.
